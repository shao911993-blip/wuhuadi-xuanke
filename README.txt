物化地选科查询（北京 2027）

1. 先把整个文件夹解压出来
2. 双击 index.html 用浏览器打开
3. 在“找学校”输入你的位次（全市排名），就能看到每所学校往年够不够得上
4. 点学校进入学校页：能报的专业组历年最低分与位次、2027 能报的专业、官方原表（各专业人数与分数段）
5. beijing2027-data.xlsx 是 Excel 资料库（含历年录取明细）
6. sources 文件夹里是北京教育考试院官方 PDF
7. 输入位次后，默认按最近一年最宽可报专业组门槛与你的位次的接近程度排序；也可切换为门槛排序或学校层级排序
8. 在列表或学校页点“收藏”，可到“我的收藏”查看；收藏保存在当前设备的浏览器中
9. 点“加入比较”选择最多 4 所学校，到“学校比较”并排查看可报专业、最近一年位次和历年门槛；比较选择也会在本机保留
10. 舊版收藏與比較選擇會自動轉換成固定學校 ID；原本的學校連結仍可使用

維護與測試方式請見 ARCHITECTURE.md。
